4 · Analytics and technical monitoring

To keep this website clear and reliable, we use two deliberately data-minimal tools. One shows us anonymously which pages are being read, so we can maintain the content sensibly (GoatCounter). The other alerts us when something is technically broken, so we can find and fix errors quickly (Sentry). Both services were chosen so that as little data as possible is collected.

GoatCounter — audience statistics

To understand which pages are viewed and how often, this website uses GoatCounter. The provider is Adrian Otruba, Belgium.

GoatCounter records page views, approximate location (country), the browser used, and the operating system. No cookies are set and no personal data is stored. IP addresses are not stored.

Use is based on Art. 6(1)(f) GDPR. The website operator has a legitimate interest in the anonymous analysis of user behaviour.

More information: goatcounter.com/help/privacy

Sentry — error monitoring

So that technical errors on this website (such as pages that fail to load or functions that crash) do not go unnoticed, we use the error-monitoring tool Sentry. This lets us detect and fix problems before they disrupt your visit. The provider is Functional Software, Inc. (Sentry), 45 Fremont Street, San Francisco, CA 94105, USA.

We use Sentry in the European data region. The error data collected is therefore processed on servers within the EU (Google Cloud Platform, Frankfurt am Main, Germany).

When a technical error occurs, Sentry transmits technical details for error analysis: the error message including its technical trace (stack trace), the browser used and its version, the operating system, the approximate location (country), the page address (URL), the time, and possibly your IP address. This data serves solely to fix errors and not to identify you as a person. The script required for monitoring is loaded on every page view; however, an error report containing the data mentioned is only transmitted if an error actually occurs. No cookies are set for this purpose.

Use is based on Art. 6(1)(f) GDPR. The website operator has a legitimate interest in the technically error-free and stable operation of this website.

As the parent company is based in the USA, processing of data in the USA cannot be entirely ruled out. Sentry is certified under the EU-U.S. Data Privacy Framework; in addition, the website operator has concluded a data processing agreement (including EU standard contractual clauses) with Sentry that ensures compliance with the European level of data protection.

4 · Analyse und technische Überwachung

Damit diese Website verständlich bleibt und zuverlässig funktioniert, setzen wir zwei bewusst datensparsame Werkzeuge ein. Das eine zeigt uns anonym, welche Seiten gelesen werden, damit wir die Inhalte sinnvoll pflegen können (GoatCounter). Das andere meldet uns, wenn technisch etwas nicht funktioniert, damit wir Fehler schnell finden und beheben können (Sentry). Beide Dienste sind so ausgewählt, dass dabei so wenige Daten wie möglich anfallen.

GoatCounter — Reichweiten-Statistik

Um zu verstehen, welche Seiten wie oft aufgerufen werden, nutzt diese Website GoatCounter. Anbieter ist Adrian Otruba, Belgien.

GoatCounter erfasst Seitenaufrufe, groben Standort (Land), verwendeten Browser und Betriebssystem. Es werden keine Cookies gesetzt und keine personenbezogenen Daten gespeichert. IP-Adressen werden nicht gespeichert.

Die Nutzung erfolgt auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO. Der Websitebetreiber hat ein berechtigtes Interesse an der anonymen Analyse des Nutzerverhaltens.

Weitere Informationen: goatcounter.com/help/privacy

Sentry — Fehlerüberwachung

Damit technische Fehler auf dieser Website (etwa fehlerhaft ladende Seiten oder abstürzende Funktionen) nicht unbemerkt bleiben, nutzen wir das Fehlerüberwachungs-Tool Sentry. So können wir Probleme erkennen und beheben, bevor sie Ihren Besuch stören. Anbieter ist die Functional Software, Inc. (Sentry), 45 Fremont Street, San Francisco, CA 94105, USA.

Wir setzen Sentry in der europäischen Datenregion ein. Die erfassten Fehlerdaten werden dadurch auf Servern innerhalb der EU (Google Cloud Platform, Frankfurt am Main, Deutschland) verarbeitet.

Tritt ein technischer Fehler auf, überträgt Sentry technische Angaben zur Fehleranalyse: die Fehlermeldung samt technischem Ablauf (Stack-Trace), den verwendeten Browser und dessen Version, das Betriebssystem, den ungefähren Standort (Land), die aufgerufene Adresse (URL), den Zeitpunkt sowie gegebenenfalls Ihre IP-Adresse. Diese Daten dienen ausschließlich der Fehlerbehebung und nicht dazu, Sie als Person zu identifizieren. Das für die Überwachung nötige Skript wird bei jedem Seitenaufruf geladen; ein Fehlerbericht mit den genannten Daten wird jedoch nur dann übertragen, wenn tatsächlich ein Fehler auftritt. Es werden hierfür keine Cookies gesetzt.

Die Nutzung erfolgt auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO. Der Websitebetreiber hat ein berechtigtes Interesse am technisch fehlerfreien und stabilen Betrieb dieser Website.

Da das Mutterunternehmen seinen Sitz in den USA hat, ist eine Verarbeitung von Daten in den USA nicht vollständig auszuschließen. Sentry ist unter dem EU-U.S. Data Privacy Framework zertifiziert; ergänzend hat der Websitebetreiber mit Sentry einen Vertrag zur Auftragsverarbeitung (inkl. EU-Standardvertragsklauseln) geschlossen, der die Einhaltung des europäischen Datenschutzniveaus sicherstellt.
